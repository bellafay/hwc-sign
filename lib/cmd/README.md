# 扩展子命令目录

一个文件 = 一个子命令，`bin/hwc-sign.mjs` 不再需要任何改动就能发现它。

```js
// lib/cmd/probe.mjs
export default {
  name: "probe",          // 省略则取文件名
  aliases: ["p"],         // 可选
  async run(argv) {       // argv 是去掉子命令名后的原始参数
    return 0;             // 数字退出码
  },
};
```

约定与理由：

- **自行解析参数**：主 CLI 的 `parse()` 对未知参数直接抛错，扩展命令走独立的参数解析，互不影响
- **不联网也能测**：把请求封装成可注入的依赖，测试里替换掉，避免 CI 打真实请求
- **名字冲突即失败**：与 `sign / call / sts` 重名、或两个文件抢同一个名字都会抛错，不静默覆盖
- 文件名以 `_` 开头不会被加载，可用来放共享辅助模块
